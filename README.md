# new-api 价格管理

跨多个 [new-api](https://github.com/Calcium-Ion/new-api) 站点，统一管理与同步模型价格的小工具。
所有价格以**真实单价（$/1M tokens）**展示与编辑，改动自动生成**可回滚快照**。

- **后端**：Go，`:8787`，提供 `/api/*` 接口并托管前端。
- **前端**：React + Vite（开发态 `:5173`），纯 CSS 零 UI 依赖。
- **数据**：本地 SQLite（`backend/data/app.db`），只存站点连接信息与快照，不入库任何密钥明文以外的东西。

---

## 功能

| 页面 | 能做什么 |
|---|---|
| **站点** | 录入/编辑接入的 new-api 站点；标记**主站/子站**（子站可从主站手动同步）；测试连接 |
| **单站编辑** | 以真实价格逐项改价；**新增/删除模型**；**批量选择 + 批量改价/删除**；模型列横向滚动时冻结固定 |
| **同步** | 以源站为基准对比目标站差异；**全选**、**预览弹窗**（before → after，确认才执行） |
| **历史** | 查看每次改动的快照；**回滚预览弹窗**（显示当前 → 回滚后），确认才回滚 |

## 快速开始（开发模式）

```bash
./start.sh
```

脚本会：检查依赖 → 首次自动 `npm install` → 同时拉起后端（`:8787`）和 Vite（`:5173`，热重载）→ 自动打开浏览器到 **http://localhost:5173**。

**停止**：在终端按 `Ctrl-C`，前后端一起关闭。

> 端口被占用会直接报错提示；改前端代码浏览器自动刷新，改后端 Go 代码需重启脚本。

## 使用说明

### 1. 录入站点

进入「站点」→ 新增站点，填写：

| 字段 | 说明 |
|---|---|
| `name` | 站点显示名（自定义） |
| `base_url` | new-api 站点地址，如 `https://api.example.com` |
| `token` | 该站点 **root/管理员账号的「访问令牌」**（Authorization） |
| `user_id` | 该账号的**用户 ID**（New-Api-User） |
| 类型 | **主站** 或 **子站**；选子站时需指定所属主站 |

> ⚠️ 工具要读写站点的定价选项（`/api/option/`），new-api 对该接口要求 **root 权限**——所以 `token`/`user_id` 必须是 **root 用户**的。填好后点「测试连接」验证。

### 2. 单站编辑

- 选站点后，表格按**真实价格**展示每个模型的 输入价 / 输出价 / 缓存价 / 图片价 / 音频价 / 按次价。
- 直接改单元格即可；**「输入价」是两个独立价格**——改它会保持其它价格不变、自动调整对应倍率（所见即所存）。
- **新增模型**：右上「+ 新增模型」→ 填模型名 + 输入价。
- **删除模型**：行尾「删除」（标记待删，可「撤销」）。
- **批量**：勾选多行（或表头全选）→ 出现操作条 →「批量改价」（选字段设固定值）或「删除所选」。
- 所有改动**暂存**，点右上「**保存改动**」才写回，并生成一个快照。

> 说明：这里的「删除模型」只清除该模型的**定价配置**，不会把模型从站点下线（模型可用性由渠道决定）。

### 3. 同步

1. 选**源站** + 勾选一个或多个**目标站** → 「计算差异」。
2. 勾选要同步的项（或表头**全选**）。
3. 「预览所选」→ 弹窗按目标站列出 `当前值 → 新值` → 「确认同步」执行、「取消」放弃。
4. 同步同样对每个目标站生成快照，可在「历史」回滚。

> 子站可在「站点」页点「从主站同步」，直接跳到本页并预置好源站=主站、目标站=该子站。
> 轻量模式：把「输入价 + 输出价」一起同步即可让两站完全一致。

### 4. 历史 / 回滚

选站点查看快照列表 → 点「回滚」→ 弹窗显示 `当前值 → 回滚后值` → 「确认回滚」。回滚本身也会生成新快照。

## 价格换算

界面显示真实价格，写回 new-api 时自动换算成倍率（基准：`输入价 = ModelRatio × 2`）：

| 显示价（$/1M） | = |
|---|---|
| 输入价 | `ModelRatio × 2` |
| 输出价 | `输入价 × CompletionRatio` |
| 缓存读价 / 缓存写价 | `输入价 × Cache(Create)Ratio` |
| 图片价 / 音频输入价 | `输入价 × Image/AudioRatio` |
| 音频输出价 | `音频输入价 × AudioCompletionRatio` |
| 按次价 | `ModelPrice`（本就是价格） |

## 生产部署（单端口）

```bash
# 1. 构建前端
cd frontend && npm install && npm run build && cd ..

# 2. 后端在一个端口同时提供 API + 页面
cd backend && go run . -addr :8787 -static ../frontend/dist -db ./data/app.db
```

访问 **http://localhost:8787**。可用 `go build -o newapiauto .` 产出二进制后台常驻。

## 数据与安全

- 站点的 `token` 明文存于本地 SQLite（`backend/data/app.db`），该文件与 `.env` 均已 `.gitignore`，不会提交。
- 每次保存/同步/回滚都会留快照，误操作可回滚。
- 仓库代码不含任何站点密钥。
